**Sky Courier** — a little 3D flight game. Eight parcels, one island, one tank of fuel. Take off from the meadow strip, thread every glowing delivery ring in order around the island — over the lake, the ridge, the summit — then bring her home and land before the tank runs dry. A hand-written canvas 3D engine (no library, no network): flat-shaded island, a red-and-white courier plane, and a full instrument panel with compass, airspeed, altimeter, artificial horizon and fuel gauge.

How to fly: `W`/`S` or `↑`/`↓` pitch, `A`/`D` or `←`/`→` bank and turn, `Shift`/`Ctrl` (or mouse wheel) throttle, mouse steers too. `F` flaps, `B` brake, `C` camera (chase/cockpit), `P` pause, `R` restart. Mind the stall, mind the fuel, and grease the landing for the bonus.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in a desktop browser. (Or serve the `game/` folder with any static server — it plays fully offline.)
